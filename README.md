# Lumo App Store website

This folder is a complete static GitHub Pages site for **Lumo: Leben in Deutschland**.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `lumo-legal`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. After deployment, enable **Enforce HTTPS** if GitHub does not enable it automatically.

For a repository named `lumo-legal`, the URLs will normally be:

- Marketing URL: `https://YOUR-USERNAME.github.io/lumo-legal/`
- Support URL: `https://YOUR-USERNAME.github.io/lumo-legal/support.html`
- Privacy Policy URL: `https://YOUR-USERNAME.github.io/lumo-legal/privacy.html`
- Terms of Use: `https://YOUR-USERNAME.github.io/lumo-legal/terms.html`

Replace `YOUR-USERNAME` with the GitHub account name.

## Optional custom domain

GitHub Pages can also use a custom domain such as `legal.lumo.kids`. Configure the domain in **Settings → Pages** and add the DNS record GitHub requests. Keep **Enforce HTTPS** enabled.
